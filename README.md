# Simulation-based inference of solar atmospheric models from Stokes profiles

This repository contains a Deep Learning architecture (Transformer + Flow Matching) for the inversion of solar atmospheric parameters using multiple spectral regions (Fe I 630 nm, Ca II 8542 A, and Ca II K).

The model implements Region Embeddings to process distinct spectral lines simultaneously and Modality Dropout during training, enabling robust inferences even when chromospheric data is missing or incomplete.

## Installation

1. Clone this repository.
2. Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Data Structure Prerequisites

The code assumes that the original synthetic data (`.h5` and `.fits` files) are located in a `dataset/` folder in the root directory.

## Execution Pipeline

### 1. Data Preparation (ETL)
Unifies the `.h5` and `.fits` formats into a single aligned master file to optimize I/O operations during training.

You need `database_630`, `database_caii` and `database_caii_k` to create unified dataset.

Change:
```python
FILE_630 = DATA_DIR / 'database_630/stokes_xxx.h5'
FILE_CAII = DATA_DIR / 'database_caii/synthetic_CaII_8542_xxx.fits'
FILE_CAII_K = DATA_DIR / 'database_caii_k/synthetic_CaII_K_xxx.fits'

OUTPUT_FILE = DATA_DIR / 'multimodal_stokes_xxx.h5'
```

`xxx` can be `training` or `testing`, generate these two datasets:

```bash
python create_multimodal_dataset.py
```

Use this script to generate `multimodal_stokes_training.h5` and then `multimodal_stokes_testing.h5`.

### 2. Normalization Statistics
The normalization_stats.npz file required for Z-score scaling of the tensors is already provided in the repository.:

```bash
python calc_stats.py
```

### 3. Training
Trains the Flow Matching model (default 50 epochs with dynamic Gaussian noise injection):

```bash
python train.py
```
*(Model weights will be saved in the `/checkpoints_multimodal` directory).*

### 4. Global Evaluation
Calculates global and filtered metrics (RMSE, MAE, R²), thermal density maps, and stratified errors by atmospheric depth log(tau):

You need `multimodal_stokes_testing.h5` and `database_models/models_testing.h5`

```bash
python evaluate.py
```
*(Evaluation results and plots will be saved in the `/plots` directory).*

### 5. Bayesian Inference and Uncertainty
Generates visualizations of individual profiles using multiple generative passes to evaluate uncertainty based on available spectral modalities:

You need `multimodal_stokes_testing.h5` (generated by script) and `database_models/models_testing.h5`

```bash
python inference.py
```

**Note:** Specific spectral lines can be toggled on/off within the `inference.py` script by modifying the boolean flags `USE_630`, `USE_CAII`, and `USE_CAII_K` to test the robustness of the Modality Dropout.
